# 意拍 IntentShot

> 说出你想拍的，剩下的交给意拍。  
> Tell it. Shoot it.

**意拍（IntentShot）** 是一款以自然语言为入口的 AI 智能相机应用。用户描述想要的画面，应用结合设备能力、实时场景与摄影策略，自动配置可控的相机参数，并支持拍摄后的效果反馈与迭代调整。

## 项目状态

- 阶段：产品定义与技术可行性验证
- 首发平台：iOS
- 首发场景建议：人像摄影
- 品牌名：意拍 / IntentShot
- 旧工作名：AI Camera（仅用于早期草案）

## 核心体验

1. 用户用自然语言描述拍摄目标。
2. 本地模型将需求解析为结构化摄影意图。
3. Vision 等视觉能力分析主体与画面状态。
4. 摄影策略引擎结合设备能力生成可执行方案。
5. 相机应用方案，用户取景并拍摄。
6. 系统评估照片与目标的匹配情况，支持继续调整。

## 技术原则

- 本地优先，尽量不上传原始照片或实时视频。
- 模型负责理解与辅助判断，确定性规则负责参数约束与执行决策。
- 所有参数在执行前进行设备能力检查与校验。
- JEV 作为可选的决策增强服务，不作为实时拍摄链路的必要依赖。
- 对设备能力、系统版本和模型可用性进行运行时检测，不将未验证能力写死。

## 当前待验证事项

- 目标 iPhone 与 iOS 版本上的 Foundation Models 可用性、模型能力与推理延迟。
- AVFoundation 对所需镜头、曝光、对焦、白平衡及拍摄模式的实际控制边界。
- Vision 在目标场景中的检测效果、性能与功耗。
- JEV 对复杂摄影策略的增益是否足以覆盖网络延迟、成本与隐私权衡。
- 用户是否更快拍出满意照片，以及是否愿意持续使用或付费。
