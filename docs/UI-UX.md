# 意拍 IntentShot｜UI/UX 交互设计说明

> 视觉概念图：[`../design/intentshot-ui-concept.png`](../design/intentshot-ui-concept.png)
>
> 口径基准：PRD v2.0（2026-09-27，`_bmad-output/planning-artifacts/prds/prd-intentshot-2026-09-27/prd.md`）。标注 **[P1]** 的内容不在 MVP 范围内；MVP 范围以 PRD §7 为准。

## 1. 设计目标

- 让用户第一眼理解：这是一款智能相机，而不是通用 AI 助手。
- 取景器是主界面和视觉中心。
- 自然语言入口要显眼，但不能阻碍构图和快门操作。
- AI 的自动行为必须透明、可撤销、可手动接管。
- 遵循 iOS 设计习惯：简洁层级、系统字体、明确主操作、适配深浅色和安全区域。

## 2. 信息架构

底部主导航建议控制在三个入口：
1. **拍摄**：取景器、自然语言入口、方案应用、快门。
2. **方案**：预设方案、我的方案、收藏和最近使用。
3. **作品** **[P1]**：照片作品浏览与方案关联（MVP 不含应用内作品页，浏览走系统照片库；视频暂缓）。

设置入口放在拍摄界面或个人设置页，不增加过多一级导航。

## 3. 核心页面

### 3.1 首次进入 / 引导
- 品牌：意拍 IntentShot。
- 主文案：把想法，拍成画面。
- 用一个真实场景示例解释流程。
- 逐步申请相机和照片权限，解释用途，不在启动时一次性堆叠权限弹窗。

### 3.2 拍摄首页 / 取景器
- 全屏或近全屏取景画面。
- 顶部：闪光灯、镜头/设置等轻量控件。
- 中部：主体提示、必要的对焦/曝光反馈。
- 底部：最近照片缩略图、快门、前后摄切换。
- 取景器上方或底部抽屉：主入口“描述想拍的画面”。
- 当前方案以小型状态标签显示，例如“人像 · 自然光”，避免大面积面板遮挡画面。

### 3.3 自然语言输入
- 标题：“你想拍出什么画面？”
- 提供少量快捷提示，如“背景虚化的人像”“暖调美食”“夜景氛围”。
- 输入框支持自然语言描述。
- 提交后进入轻量分析状态；用户可取消并回到取景器。

### 3.4 AI 分析状态
- 展示清晰但克制的进度状态，例如“正在分析场景并准备拍摄方案”。
- 用简短步骤说明：理解需求、分析画面、适配相机。
- 不展示虚假的实时推理过程或不确定的百分比。

### 3.5 拍摄方案预览
- 顶部显示方案名称和示例效果/当前取景缩略图。
- 仅展示用户能理解的关键策略：模式、镜头建议、对焦目标、光线/色调策略。
- 显示“设备限制”或“无法完全实现”的目标。
- 主按钮：“应用方案”；次按钮：“修改需求”。
- 具体参数可折叠到“高级设置”，避免普通用户被参数淹没。

### 3.6 已应用方案 / 实时拍摄
- 返回取景器，显示“方案已应用”轻提示。
- 快门始终是最突出操作。
- 默认"仅建议"模式：场景变化时以建议卡出现（单次 ≤2 条），用户点击才应用；设置中可切换"自动应用 + 一键撤销"。
- 支持手动接管与参数锁定；撤销为会话内栈式撤销（至少最近 5 步）。
- 场景变化时只在有明显价值时提示，不频繁弹出建议。

### 3.7 拍摄结果页
- 大图展示成片。
- 轻量显示“目标达成情况”，例如“人物清晰”“背景虚化：部分达到”。
- 操作：保存、重拍、调整效果。
- 不用单一分数评价照片审美。

### 3.8 自然语言调整面板
- 输入示例（参数类）：“脸部再亮一点，画面整体偏暖。”
- 调整诉求分三类（PRD FR-12）：参数类直接调整参数；模式类切换拍摄模式（如启用系统人像模式获得虚化）；构图引导类（如“人物往中间一些”）仅给出引导建议，不改变相机状态。
- 显示本次将修改的目标，以及会保留的目标。
- 应用后可撤销。
- 若硬件无法独立控制主体与背景亮度，应说明限制并给出替代建议。

### 3.9 方案库
- 分类：MVP 预设白名单为 3 个人像变体（自然人像、电影感人像、逆光人像）；美食/静物、旅行/风景、夜景分类随版本开放 **[P1]**。
- 每个方案展示适用场景、核心效果和限制。
- 支持收藏、复制、重命名和删除。

### 3.10 作品页 **[P1]**
- 本页整体为 P1 预研：MVP 不含应用内作品页，浏览走系统照片库（PRD FR-10、假设 A-9）。
- 照片网格和时间分组。
- 作品可关联拍摄方案，方便复用。
- 不做社交社区；视频作品暂缓。

### 3.11 设置
- 默认拍摄偏好。
- 自动辅助开关。
- 本地处理与云端决策选项（若启用 JEV）。
- 数据管理、权限状态、帮助与反馈。

## 4. 关键交互状态

| 状态 | UI 表达 | 用户可操作 |
|---|---|---|
| 等待输入 | 取景器 + 输入入口 | 拍摄、输入、选方案 |
| 解析中 | 轻量进度提示 | 取消 |
| 需要澄清 | 单一问题卡片 | 选择/补充 |
| 方案就绪 | 方案摘要卡 | 应用、修改 |
| 应用中 | 轻量状态提示 | 取消（若可安全取消） |
| 已应用 | 小型状态标签 | 拍摄、撤销、手动调整 |
| 实时建议 | 建议卡（默认模式，点击才应用） | 接受、忽略、关闭 |
| 部分支持 | 明确标出限制 | 接受折中、修改目标 |
| 拍摄中 | 快门反馈 | 按相机流程操作 |
| 结果分析中 | 结果页轻量加载 | 等待/跳过 |
| 分析完成 | 成片 + 目标反馈 | 保存、重拍、调整 |
| 降级模式 | 说明 AI 不可用并保留基础拍摄 | 继续拍摄、重试 |

## 5. 视觉规范建议

- 基础：系统字体、动态字体、系统安全区域。
- 主色：清透蓝；AI 分析状态可用少量蓝紫渐变。
- 背景：白/系统背景，取景器以实际画面为主。
- 卡片：圆角、细分隔线、轻量阴影；避免过度玻璃拟态。
- 动效：短、克制、为状态变化服务；不影响快门响应。
- 深色模式：拍摄界面优先适配暗色，设置与方案页遵循系统外观。
- 无障碍：VoiceOver 标签、对比度、动态字体和可触达控件尺寸。
